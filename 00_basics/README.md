# Start here: the basics

This unit assumes **no** background. It teaches the words and the Python that the rest of the course
uses without explaining. Do it before the Foundations unit.

| Lesson | What you'll learn |
|--------|-------------------|
| [B1: Glossary](B1_glossary.md) | Every term in the course, in plain English, with one running example (a table of fruit). Come back here whenever a word confuses you. |
| [B2: Python basics](B2_python_basics.md) | The Python the course code uses: lists, indexes, loops, functions, classes, `self`, and reading error messages. |
| [B3: Your first model](B3_first_model.md) | A tiny end-to-end example that uses all the words: data, features, labels, fit, predict, accuracy. |

**Lab:** [practice.py](practice.py) has 12 small exercises (one or two lines each). Run the checks in the course app,
or with `python 00_basics/example.py my_practice`. If you get stuck, [explained.py](explained.py) has the answers, with every line explained.

**How to study each lesson**

1. Open a Python shell: run `.venv\Scripts\python` in the terminal. You'll see `>>>`.
2. Type `import numpy as np`, then type every example from the lesson yourself and look at what it prints.
3. Change the examples a little (other numbers, another index) and predict the result *before* pressing Enter.
4. To leave the shell, type `exit()`.

Typing the examples yourself matters more than reading them.
